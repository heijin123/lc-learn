学习建议

  • 理论实践 1:1 — 每学完一个概念立即动手写代码，不要囤积理论。每个时间块的「实践」部分都是核心。
  • 一个 API Key 走天下 — 建议用 OpenAI API（或兼容接口），所有框架都原生支持，避免环境问题浪费学习时间。
  • 优先跑通再深究 — 先让代码跑起来看到效果，再回头读源码理解原理。正向反馈比完美主义重要。
  • 不要一次学完所有视频 — 中文视频课程（LangChain/LangGraph/AutoGen/CrewAI）每门几十集，按计划对应章节学，完成一章 → 动手复现 → 再学下一章。
  • Hello-Agents 是主线 — 你已经在看这个教程，它将作为 21 天计划的主干，其他资源是支线补充。
  • 做好笔记和代码管理 — 每天的实践代码用 Git 管理，学完一周做一次总结回顾。
  • 加入社区 — LangChain Discord、Datawhale 社区、AutoGen GitHub Discussions，遇到问题及时求助。
  • 成本意识 — 用 GPT-4o-mini 做开发测试，GPT-4o 做最终验证。GroupChat 场景注意控制轮数防止 Token 爆炸。
  • 毕业项目要拿得出手 — Day 21 的毕业项目要做成可以放进简历/作品集的质量，包含完整文档和在线 Demo。
